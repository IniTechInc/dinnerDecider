                  Camera and TLS

                  The photo button opens your phone camera app over plain HTTP, so most people never need a certificate. The live preview needs a secure page, which a LAN address is not.

                  To unlock the live preview, install this server's certificate authority on the device and trust it fully. A certificate authority whose private key sits on a Raspberry Pi can impersonate any site to that device: a fair homelab trade, a poor one for a work phone.
